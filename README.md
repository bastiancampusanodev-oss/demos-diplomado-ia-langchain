# Demos Diplomado IA y Automatización Empresarial

Repositorio con demos prácticas del Módulo 1 del Diplomado.

## Contenido

### Clase 3 - RAG / LangChain
Demo asociada a recuperación de información, documentos y uso de LangChain.

### Clase 4 - Agente controlado con tools
Demo de agente de mesa de ayuda interna.

El agente recibe un caso, decide si corresponde usar herramientas, calcula prioridad, consulta política de soporte, genera un plan sugerido y muestra la traza de ejecución.

## Requisitos generales

- Python 3.10+
- Entorno virtual recomendado
- API key de OpenAI configurada localmente en un archivo `.env`

## Importante

Este repositorio no incluye archivos `.env` ni claves API.
Cada estudiante debe crear su propio archivo `.env` local si desea ejecutar las demos.
